# У врача · Русский язык A2

Иллюстрированный электронный ресурс для ознакомления с языковым материалом урока.

- 6 лексических тем, 107 слов и моделей с примерами, толкованиями и китайскими эквивалентами.
- 107 исходных карточек и 107 пиктограмм, сохранённых без изменения PNG.
- 6 разных сюжетных иллюстраций.
- Флеш-карты «картинка → слово» и «слово → значение».
- Действия участников и 10 блоков языковых схем: речевые формулы, части речи, словообразование, склонение, спряжение, вид, сочетания слов, управление, конструкции и контрасты.

## Просмотр

Начните с карты лексических тем. Выберите тему, группу слов и режим: знакомство, исходные карточки или флеш-карты. В разделе «Схемы урока» можно раскрывать отдельную ветвь интеллект-карты и выделять падеж в таблице.

Флеш-картами управляет преподаватель: стрелки ← и → меняют карточку, пробел раскрывает ответ. «Демонстрация» скрывает управление, Escape возвращает его.

Нумерация 2.1–2.6 сохранена из языковой карты: 2 — номер лексического раздела документа, не номер темы в курсе.

## Сохранение и публикация

Все необходимые изображения, оформление и взаимодействие встроены в `index.html`. Для локального просмотра скачайте этот файл и откройте в браузере. Установка программ и интернет для локального просмотра не требуются.

Для GitHub Pages выберите ветку `main` и папку `/ (root)`. После включения сайт доступен по адресу https://lasveta1sl-bot.github.io/u-vracha/.

Исходные документы и материалы преподавателя сохранены отдельно в локальном архиве. В публичный ресурс они не включены. Полная версия проекта с отдельными файлами оформления, данных и PNG также сохранена локально для редактирования. Встроенные PNG проверены по контрольным суммам и совпадают с оригиналами.
