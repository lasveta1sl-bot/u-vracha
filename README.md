# У врача · Русский язык A2

Электронный ресурс для ознакомления с языковым материалом урока.

- 6 лексических тем, 107 слов и моделей с толкованиями, китайскими эквивалентами и примерами.
- 107 исходных карточек и 107 пиктограмм. PNG сохранены без изменений.
- 6 различных сюжетных иллюстраций.
- Флеш-карты «картинка → слово» и «слово → значение» с управлением преподавателя.
- Действия участников, коммуникативные формулы, интеллект-карты, склонение, спряжение, вид, сочетаемость, управление, речевые модели и контрасты.
- Режим демонстрации, адаптация к небольшим экранам и печати.

## Как пользоваться

Откройте `index.html` в браузере или опубликованный сайт. Начните с карты лексических тем, затем выберите группу слов и режим просмотра. Во флеш-картах стрелки ← и → меняют карточку, пробел показывает или скрывает ответ. Кнопка «Демонстрация» убирает элементы управления; Escape возвращает их. В разделе «Схемы урока» можно выбрать блок, ветвь интеллект-карты и падеж для сравнения форм.

Нумерация 2.1–2.6 сохранена из исходной языковой карты: 2 — номер её лексического раздела. Это не номер темы «У врача» в курсе. Остальные блоки соотносятся с примечаниями преподавателя к документу.

## Публикация

Статический сайт: HTML, CSS, JavaScript и локальные изображения. Зависимости, сборка, сервер приложения и внешние сервисы не требуются. Для GitHub Pages: ветка `main`, папка `/ (root)`. Все пути относительные, поэтому сайт работает в подпапке `/u-vracha/` и при открытии локального файла.

## Материалы и сохранность

Исходные документы и материалы преподавателя сохранены отдельно в локальном архиве и не включены в публичный сайт. Иллюстрации созданы для этого урока; описание их сюжетов сохранено в локальном комплекте. Учебные примеры воспроизводят язык медицинских ситуаций.

При обновлении редактируйте `assets/lesson-data.js`, оформление — `assets/styles.css`, взаимодействие — `assets/app.js`. Контрольные суммы PNG находятся в `assetManifest` в файле данных.
