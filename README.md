# У врача · Русский язык A2

Сайт для ознакомления с языковым материалом урока: 6 лексических тем, 107 слов и моделей, 107 исходных карточек, 107 пиктограмм, 6 сюжетных иллюстраций и 11 разделов языковых схем.

## Для занятия

Выберите лексическую тему, группу и режим просмотра. Во флеш-картах стрелки ← и → меняют карточку, пробел раскрывает ответ. Кнопка «Демонстрация» скрывает управление, Escape возвращает его. В разделе «Схемы урока» доступны интеллект-карты, формы, управление и речевые модели с примерами.

Нумерация 2.1–2.6 соответствует лексическому разделу исходной языковой карты.

## Сохранение и публикация

Сайт: https://lasveta1sl-bot.github.io/u-vracha/.

GitHub Pages: ветка `main`, папка `/ (root)`. Сборка и установка зависимостей не нужны. Для локального просмотра скачайте весь репозиторий и откройте `index.html`.

Пиктограммы и исходные карточки загружаются пакетами по темам: один запрос для пиктограмм выбранной темы и отдельный запрос для её исходных карточек. При сбое пакет загружается повторно. Все 214 исходных PNG внутри пакетов сохранены без изменений. Облегчённые сюжетные иллюстрации загружаются отдельно и не задерживают появление управления уроком. SVG-контейнеры также сохранены как резервные исходники. Дополнительные сюжетные иллюстрации подготовлены в облегчённом формате для экрана; их оригиналы сохранены в локальном архиве. Материалы преподавателя и исходные документы хранятся отдельно от публичного сайта.

Данные: `assets/lesson-data.js`; оформление: `assets/styles.css`; взаимодействие: `assets/app.js`.
